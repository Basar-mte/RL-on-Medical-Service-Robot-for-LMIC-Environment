# Hiwonder MentorPi meshes (not included)

`mentorpi_ackermann.urdf` uses the vendor CAD meshes of the Hiwonder MentorPi Ackermann chassis. They are Hiwonder's files and are not redistributed in this repository.

Copy these files from the MentorPi ROS 2 package supplied with the robot into this folder before building the Isaac Sim robot:

```
base_link.STL  cam_Link.STL  lidar_Link.STL
wheel_lb_Link.STL  wheel_lf_Link.STL  wheel_rb_Link.STL  wheel_rf_Link.STL
```
