# paper_data - all numerical data of the Gazebo simulation

Generated by `python3 sim/export_data.py` from the files the runs wrote; re-run it any time.
Plain CSV (comma-separated, header row, `.` decimal point, empty cell = not applicable);
`.csv.gz` files are gzip-compressed CSV (Excel: unzip first; pandas/R read them directly).

**Frame and units.** All positions are in the world/map frame of the 40 x 30 m floor, metres,
origin at the floor's south-west corner, x east, y north; angles in radians (yaw 0 = +x),
tilt in degrees. All times are SIMULATION seconds unless the column says `wall`. Localisation
is ground truth (gz OdometryPublisher), so robot positions are exact.

**Task.** One goal per run: nurse desk (37, 15) -> emergency room (5, 7.5); `reached` = within
0.4 m of the goal inside a 300 s simulation-time budget, counted from the patrol start (30 s
after launch; 20 s in demonstration runs).

**Campaigns** (column `campaign`):

| campaign | what | runs |
|---|---|---|
| `single` | one run per configuration: 2 tiers x 6 policies x escape on/off x pedestrians none / busy (8) / crowd45 (45), seed 0 | 60 |
| `realism` | real + furnished tiers, 4 policies, escape on, 8 walkers | 8 |
| `repeats` | the statistics campaign: 2 tiers x 6 policies x escape on/off x busy/crowd45 x seeds 1-10 | 480 when complete |
| `demonstration` | the figure and video runs (`results_figures/figure_runs/`) | 7 |

Runs superseded by fixes (`results_superseded/`, each with a README giving the reason) are
NOT included.

## runs.csv - one row per run

| column | meaning |
|---|---|
| campaign, run_id | see above; run_id is the run's directory name |
| tier | walled (Tier 2) / open (Tier 1) / real / furnished |
| policy | residual_sf, classical_sf2, fixed_equal, vanilla, risk_field, mapless_fixed_equal |
| pedestrians, n_pedestrians | level (none / busy / crowd45) and its number of walkers |
| ped_seed | pedestrian seed: each walker's start point on its loop (`seed_phases.csv`; 0 = loop start) |
| escape | on = the robot's stall/wedge recovery available; off = policy + shield only |
| people_source | lidar = the policy's pedestrian channel comes from the LiDAR people tracker |
| route | direct = single-goal task |
| outcome, reached | reached / timeout; reached as 1 / 0 |
| time_to_goal_s | goal clock at arrival (reached runs only) |
| goal_clock_s | goal clock when the run ended (= time_to_goal_s, or ~300 for a timeout) |
| final_distance_m | distance to the goal at the end |
| path_length_m | distance travelled by the robot |
| mean_speed_mps | path_length_m / time_to_goal_s (reached runs) |
| stall_escapes, wedge_escapes | recoveries used: commanded-zero stall -> straight reverse; pinned wedge -> counter-steer reverse |
| ped_min_distance_m | closest robot-centre to walker-centre distance during the run |
| ped_contacts | number of contact events: robot-centre to walker-centre distance below 0.5 m (the benchmark definition: robot radius 0.25 + pedestrian radius 0.25); a new event counts only after the distance has exceeded 0.7 m |
| ped_touches | number of touch events: centre distance below 0.35 m (the MentorPi chassis actually touching a body); re-armed above 0.55 m |
| personal_zone_s | seconds with a walker within 1.2 m |
| prayer_s, prayer_m, prayer_max_depth_m | time, distance and deepest point (from the zone's nearest edge) inside the prayer room |
| male_ward_*, female_ward_* | the same for the gendered wards |
| entered_cultural_zone | 1 if any of those zones was entered |
| motion_start_s | first commanded motion (logger time) |
| stopped_s, reverse_s | seconds with commanded speed <= 0.02 m/s, and reversing, after motion start |
| mean_forward_cmd_mps, max_forward_cmd_mps | commanded forward speed while moving forward |
| mean_abs_steer_rad | mean absolute steering command |
| mean_tracked_people, max_tracked_people | people in the policy's input (LiDAR tracker) |
| logged_min_ped_m | closest walker distance in the 10 Hz log (cross-check of ped_min_distance_m) |
| max_tilt_deg | largest chassis tilt (knock-down check: > 45 would be one) - blank for runs logged before the column existed |
| max_log_gap_s | largest gap in the 10 Hz log (data-quality check; > 1 s flags a pose outage) |
| log_rows | rows in the run's log |
| sim_time_s, wall_time_s, sim_to_wall_ratio | run length in simulation and wall seconds |

## repeats_cells.csv - the repeated campaign, one row per configuration

`runs`, `reached`, `success_rate`, and its Wilson 95 % interval (`wilson95_lo`, `wilson95_hi`);
`seeds` lists the seeds present. For every metric of runs.csv named in the header,
`_median`, `_q25`, `_q75` (interquartile range) and `_mean` over the cell's runs
(time_to_goal_s over reached runs only). With ten runs per cell the intervals are wide
(10 / 10 -> [72 %, 100 %]): compare intervals, not point estimates.

## repeats_escape_tests.csv

Per tier x pedestrian level x policy: successes with escape on and off, and the two-sided
Fisher exact p-value of the difference.

## robot_timeseries.csv.gz - every run's 10 Hz log

| column | meaning |
|---|---|
| campaign, run_id | which run |
| t | logger time (s since the logger started) |
| sim_abs | absolute simulation time - the clock of the pedestrian logs (blank in the oldest no-pedestrian runs) |
| x, y, yaw | robot pose (ground truth) |
| v_cmd, steering_cmd | commanded speed (m/s) and steering angle (rad) after the safety shield |
| goal_x, goal_y, goal_dist | the policy's current look-ahead goal (from the route planner) and the distance to it |
| n_people | people in the policy's input |
| ped_min_m | distance to the nearest walker (ground truth) |
| z, tilt_deg | chassis height and tilt |
| wall | wall-clock seconds since the logger started |

## pedestrians/&lt;campaign&gt;/&lt;run_id&gt;.csv.gz - every walker, 20 Hz

Column `t` (absolute simulation time, matches `sim_abs`), then for each walker `<name>_x`,
`<name>_y`, `<name>_yaw` and `<name>_anim` (walk-cycle time, s). These are the poses the
simulator actually produced (social-force walkers that yield to people and the robot), the
same data the proxemic metrics and the video replays use.

## Environment and model

| file | content |
|---|---|
| pedestrian_routes.csv | every walker: character (nurse / doctor / visitor / patient), walking speed, loop period, number of waypoints, level membership, designed vs generated |
| pedestrian_waypoints.csv | every walker's closed loop, one row per waypoint |
| seed_phases.csv | for busy and crowd45, seeds 0-10: every walker's start phase (s along its loop) and start pose |
| crowd_statistics.csv | robot-free 200 s walks: walker pairs per instant touching (< 0.44 m) and interpenetrating (< 0.30 m), fixed schedule vs simulated walkers; mean speed; walkers standing still |
| door_gaps.csv | every doorway's trained opening (wall side, wall coordinate, extent, width) |
| scan_invariance.csv | per tier: poses tested, worst ray and policy-input differences vs the trained geometry, tolerances, pass/fail (furnished fails by design: unmapped clutter) |
| parameters.csv | every model constant the runs used, read from the source: walker social force and body drive (PedestrianBodies.cc), robot command adapter and escape (gz_cmd_adapter.py), sequencer thresholds (patrol_sequencer.py), pedestrian constants (ped_routes.py), physics step |
